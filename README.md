# pyScan

A fast, lightweight and simple TCP port scanner written in Python

## Getting Started

1. Clone the repo
2. Install the dependencies (req.txt; `pip install -r req.txt`)
3. Run: `python pyscan.py`

## Tests
The test file exists as `tests/`, and checks if the script can succesfully
scan open ports, closed ports, and a range.
